# 小猿搜题 Loon 去推广插件

v0.2.0 · 2026-10-26 · 基于用户提供的 iOS HAR 与开屏录屏制作，尚未经过手机端实测。

0.2.0 新增：拦截开屏「双11大促 VIP全年最低价」等首页活动配置（solar-sync 接口的 homepageActivity）。

## 安装

插件订阅地址：

https://raw.githubusercontent.com/lpleasure/xystads-loon/main/XiaoYuanSearchAdBlock.plugin

1. 在 Loon 的「插件」页面新增上面的 URL，下载并启用。
2. 开启 Loon 的脚本和 MITM 功能。首次使用 MITM 时，按 Loon 提示安装证书，并在 iOS「设置 → 通用 → 关于本机 → 证书信任设置」中开启该证书的完全信任。
3. 确认插件的 MITM 主机包含 xyst.yuanfudao.com，脚本下载成功。
4. 完全退出小猿搜题后重新打开，检查开屏、首页、优学页、搜题结果页及购买后推荐弹窗。开屏素材是上次启动时预先下载的，启用插件后第一次冷启动仍可能出现一次；请再冷启动 1～2 次确认。
5. 如出现异常，关闭此插件再重启小猿搜题即可回退。原有缓存可能导致推广短暂残留；本插件不会自动清理 App 数据。

如果已有其他插件改写同一活动接口，先停用重叠规则。Loon 对同一响应通常只选中第一条匹配的响应脚本，重叠可能使本插件不执行。

## 当前过滤范围

### 开屏 / 首页活动（v0.2.0）

App 冷启动时向 `POST /solar-sync/iphone/sync` 请求 `{"keys":["homepageActivity"],...}`。HAR 中其他明文接口都没有开屏素材或「双11大促」文案，只有这个响应无法查看：14320 字节、16 字节对齐、熵约 8 bit/字节，判断为加密数据，无法逐条改写。

因此本插件在请求阶段处理：

- 只请求 homepageActivity 时：由 Loon 直接返回 200 空响应，不再请求服务器；
- 同时请求其他键时：只从 keys 中删除 homepageActivity，其余键照常同步；
- 非 POST、非 JSON、不含该键的请求原样放行。

这样会同时去掉开屏活动及首页的运营活动（如「双11大促 · 全年最低价」卡片，如果它也来自这项配置）。这个判断来自抓包推断，尚未经过设备验证。

### 活动接口

只对以下 HTTPS GET 请求的成功 JSON 数组响应做过滤：

- /solar-activity/iphone/activity-open/2
- /solar-activity/iphone/activity/2/数字

去除：

- resultpage.vip.banner.solar：搜题结果会员推广横幅。
- solar.dialog.blank：仅限抓包确认的页面条件与营销跳转组合：
  - 首页活动落地页、教辅推广页、课程销售页；
  - 优学页会员购买弹窗；
  - 购买成功后的课程销售推荐。

未知位置或未知弹窗跳转保留。非数组、无效 JSON、二进制响应、错误状态均原样放行。

## 保留范围

活动接口也下发首页功能，不能整体返回空数组。本插件保留错题本、课文点读、计算器、英语学习、试卷等入口，以及口算历史页通往口算练习的功能横幅。

会员权限、试用限制、视频试看提示、登录、搜题、解题、支付和风控接口均不修改。此插件不提供会员解锁。图片 CDN、遥测域名也不整域拦截，避免误伤题目图片和其他功能。

未发现第三方广告 SDK 的开屏接口；开屏为 App 自家活动。本版本不宣称移除所有内嵌静态广告或客户端本地推广。

## 验证结果

- 8 组自动化测试通过：活动过滤 4 组；开屏同步拦截、混合键保留、异常放行、URL 边界 4 组。
- 本地回放 2026-10-25 的 299 条 HAR 请求：匹配 4 条，修改 3 条，其余不变。
  - solar-sync（homepageActivity）：改为本地空响应。
  - 聚合活动响应：56 → 50，移除 1 条横幅和 5 条营销弹窗。
  - 单独会员横幅响应：1 → 0；activity/2/324 原本为空，不变。
- 保留全部 48 条首页功能配置、1 条口算功能横幅、1 条视频试看提示。

这些是离线响应验证结果，不是设备端验收。导入后建议测试：冷启动、拍照搜题、查看答案、错题本、课文点读、登录和正常视频播放。若开屏连续冷启动后仍出现，请在启用插件的状态下重新抓包，确认 solar-sync 请求是否被拦截，并检查同一时段是否出现了新的配置接口。

## 开发

Node.js 18 或更新版本，无第三方依赖：

    npm test

脚本不发起额外网络请求、不保存响应、不打印 Cookie 或令牌。测试数据为人工构造，仓库不包含原始 HAR、账号信息、设备标识或抓包中的完整鉴权 URL。
